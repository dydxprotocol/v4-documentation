# Noble API

:::warning[Deprecated for deposits]
Since the v9.9 upgrade, Noble-to-dYdX deposits are rejected (code 13) and refunded on Noble, so do not use the Noble client to deposit. It can still be used for withdrawals through Noble until governance closes the Noble exit. See the [Canonical USDC integrator guide](/interaction/deposits-withdrawals/usdc-migration).
:::
