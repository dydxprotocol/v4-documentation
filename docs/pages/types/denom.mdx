# Denom

`Denom` is an enum consists of the following values

- `Usdc`: USDC on dYdX (`ibc/8E27BA2D5493AF5636760E354E46004562C46AB7EC0CC4C1CA14E9E20E2545B5`). Show it as "USDC", not "Noble USDC".
- `Dydx`
- `DydxInt`
- `NobleUsdc`: USDC on the Noble chain (`uusdc`), used by the Noble client.
- `Custom`
